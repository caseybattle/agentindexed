How to choose frameworks & sdks

  1. Decide between code-first (Python/TypeScript) and declarative orchestration
  2. Check protocol support — MCP, tool calling, agent-to-agent messaging
  3. Weigh community size and production adoption before committing

Common use cases

  • Building custom single or multi-agent applications
  • Orchestrating role-based agent teams for complex workflows
  • Adding tool use, memory, and planning to LLM apps
